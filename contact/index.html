Support and issue reporting

Something broke? Use the fastest route to get it fixed.

GitHub is best for reproducible bugs and direct tracking. Email is better when you need to describe a problem privately or quickly send context from a restricted network.

Open GitHub Issues

Main site blocked on your network?

Use the GitHub Pages mirror as the corporate-accessible fallback.

https://sarthakworks.github.io

Raise an issue on GitHub

Best for visible tracking, reproducible bugs, and UI regressions.

1

Open the mirror repository

Use https://github.com/sarthakworks/sarthakworks.github.io because it is the public mirror users can access from restricted networks.

2

Create a new issue

Open the Issues tab and click New issue.

3

Include the details needed to reproduce it

  • Exact page URL or tool name
  • Expected result vs actual result
  • Browser, device, and network restrictions if relevant
  • Screenshots, console errors, or the steps that trigger the bug

Contact us

support@nolimify.com.

For trackable public bugs, GitHub Issues is still the preferred path.
